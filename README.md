# Daily Quote

A minimal, responsive quote generator with mood filters, quote attribution, and a save-as-text button.

## Features
- Random quote on first open
- New quote button avoids repeating the current quote when possible
- Quote and author clearly displayed
- Mood/category filter and text download
- No API key or external service required

## Run
`pip install -r requirements.txt`
`streamlit run app.py`
