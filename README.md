# Random Quote Generator

A minimal, clean Streamlit app that displays a random inspirational quote on opening and whenever **New Quote** is clicked.

## Features
- Random quote on first load
- Quote text and author attribution
- Avoids showing the same quote twice in a row when possible
- No API key or external service required

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Deploy this repository on Streamlit Community Cloud and set the main file to `app.py`.
